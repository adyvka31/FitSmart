## 📖 About The Project

**FitSmart** was developed to bridge the gap between people and a healthier lifestyle. Despite a busy academic schedule, this project was successfully brought to life using HTML, CSS, and JavaScript. It serves as a centralized platform offering health education, dietary guides, fitness routines, and an innovative AI-powered consultation feature.

## ✨ Key Features

* **📖 Health Education:** Provides research-based articles, actionable tips, and valuable insights on nutrition, exercise, disease prevention, and overall well-being.
* **🥣 Healthy Eating Guide:** Offers personalized recommendations for nutritious foods and balanced daily meal plans tailored to specific dietary needs and lifestyles.
* **🚴🏻‍♂️ Fitness & Physical Activity Guide:** Suggests customized exercise routines for various fitness levels and health goals, catering to everyone from beginners to advanced users.
* **🩺 AI-Powered Doctor Consultation:** Features an accessible tool enabling users to consult directly with healthcare professionals online at no cost, breaking down barriers to medical advice.

## 🛠️ Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3
* **Logic/Interactivity:** JavaScript (Vanilla)

## 🚀 Getting Started

Since this is a web-based project built with fundamental web technologies, running it locally is straightforward.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/adyvka31/fitsmart.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd fitsmart
    ```
3.  **Run the project:**
    * You can simply double-click the `index.html` file to open it in your default web browser.
    * *Alternatively (Recommended):* If you use VS Code, you can use the **Live Server** extension (which runs on port `5501` as configured in `.vscode/settings.json`) to run the project and see real-time changes.
